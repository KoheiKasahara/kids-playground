# ドットカート

`/games/pixel-kart` で遊べる、横画面専用のドット絵カートレースです。4歳でも操作に迷いにくいよう、自動アクセル・自動ドリフトで走り、ハンドルとアイテムだけを操作します。森・海岸・クリスタル洞窟・空の4コースを、それぞれ2周してゴールします。

## 操作

| 操作 | スマートフォン・タブレット | PC |
| --- | --- | --- |
| ハンドル | 左のスティックを左右へ動かす | 左右矢印、または A / D |
| アイテム | 右のアイテムボタン | スペース |

アクセルとブレーキのボタンはありません。速く走っているときのカーブでは自動でドリフトします。縦向きでは端末を横向きにする案内を表示し、レース中に画面を離れると一時停止します。

コース補助は初期状態でオンです。端へ近づくとコース内へゆるやかに戻すため、初めての子どもも走り続けられます。設定からオフにすると、自分でハンドルを調整する遊び方に切り替えられます。

## コースのしかけ

操作が少なくても走り方で差がつくよう、各コースに次のしかけを入れています。

| しかけ | 内容 |
| --- | --- |
| 道幅の変化 | 細い小道・桟橋・トンネルと、広い砂浜や広場がある |
| わかれみち | 道の中央の島で道が2本に分かれる。内側は短いがざらざら、外側はダッシュばん、など道ごとに損得がある |
| ざらざら | 泥・潮だまり・がれき・雲のかたまり。上を走ると遅くなる（ジャンプ中・無敵中は平気） |
| ダッシュばん | 上を通ると短く加速する |
| インコース | カーブの内側を走ると少し早く進み、外側にふくらむと少し遅れる |
| アイテムボックス | 横一列ではなく斜め・左右の片側・わかれみちの中などに散らばり、ボックスの上を通ったときだけ取れる |

CPU もボックス・ダッシュばんを狙い、ざらざらと島をよけて走ります。キーボードのハンドルは押し始めがなめらかで、短く押すと小さく曲がれます。

## アイテム

コース上のアイテムを取ると、右のボタンから使えます。

| 種類 | 効果 |
| --- | --- |
| 加速 | 一時的に速く走る |
| ジャンプ | 飛び上がって路面のおじゃまをかわす |
| 無敵 | 一定時間、おじゃまを受けずに走る |
| 追尾ばくだん | 前を走る相手を追いかける |
| おじゃま | 路面におじゃまを置いて後続のカートを妨害する |

妨害による停止は短く、再加速を速くしています。続けて当たって走れなくなる状況を避ける保護時間も設けています。

## 実装と確認

ゲーム本体は `src/games/pixel-kart/` にまとめています。`engine.ts` でレースの進行・アイテム、`courses.ts` でコース形状と道幅・しかけ・ボックス配置を扱い、`render.ts` / `sprites.ts` で Canvas のドット絵、`audio.ts` でコース別BGMと効果音を生成します。`PixelKartPlay.tsx` は画面と入力、`ItemGlyph.tsx` は共通のアイテム表示を担当し、`types.ts` がコース・カート・アイテム・レース状態の共通定義です。

ホームのカード・あそびかた・SEO・sitemap・直接アクセス用の静的HTMLは `src/games/gameCatalog.ts` の登録を共通の情報源にします。`src/app/routes.tsx` からゲームを遅延読み込みし、戻るボタンとプレイ中の説明文の表示はゲーム画面側で管理します。

`e2e/pixel-kart.smoke.spec.ts` は通常の `npm run test:e2e` に含まれます。全ゲームの初期画面・縦横レイアウトの Nightly テストも、カタログ登録から自動的に対象へ加わります。
