# ちきゅうぎ・たいようけい

> この文書は長期的な設計・運用方針を扱う。個別機能の最新仕様は GitHub Issue、現在の詳細挙動・パラメータは実装コードとテストを正とする。

## 概要

地球や太陽系の天体をさわって回しながら観察するミニゲームです。クイズの正解を探すのではなく、天体に触れて動かすこと自体を楽しむビューワーとして設計しています。「ちきゅうぎ」は地球、「たいようけい」は太陽系の各天体を対象にしており、どちらも同じ考え方の3D表示・データ駆動の構成を共有しています。

## 主な特徴

- 天体本体をドラッグして回す、ズームで近づく・離れるといった、直感的な操作だけで完結します。
- 天体の情報はコードに埋め込まず、データとして定義し、表示ロジックはそのデータを読んで描画します。
- 「たいようけい」は複数の天体を切り替えて観察できますが、天体ごとに専用の分岐コードを増やさず、共通の描画ロジックがデータの違いを反映する形にしています。

## 技術 / 主要実装

- 描画には Three.js を使います。
- 地理・天体データはビルド時に生成・簡略化した静的データとして同梱し、実行時に重い変換処理を行いません。
- 天体・国のデータ定義とレンダリングの間の責務を分離し、見た目の調整はデータ側、描画の仕組みは共通コード側で扱います（`src/games/earth-globe/`、`src/games/planet-globe/`）。

## 設計上の注意

- 地球と個々の惑星で見た目や特徴は異なりますが、その違いはデータの差として表現し、天体ごとに重複した実装を増やさないことを優先します。
- カメラ・描画・天体データの責務を分けておくことで、天体を追加してもカメラや操作の仕組みに手を入れずに済む構造を保ちます。
- モバイル端末での描画負荷を意識し、表示品質より快適な操作感を優先する判断をとることがあります。
- 個々の天体の見た目・数値・挙動は変更されやすいため、この文書では扱わずコードを正とします。
