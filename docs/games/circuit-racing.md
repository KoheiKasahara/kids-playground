# サーキットレース

仕様の正本は [Issue #557](https://github.com/KoheiKasahara/kids-playground/issues/557)。幼児が好きな車と色を選び、自動で走る様子を楽しむゲームです。`/games/circuit-racing` 内で選択と走行を切り替えます。

## 走行の考え方

操作や衝突に依存する物理シミュレーションではなく、閉じた走行ラインと車種性能から周回用の速度プロファイルを作ります。曲率によるコーナー速度制限に、進行方向の加速制限と逆方向の制動制限を適用することで、曲がる手前から減速して出口で再加速します。閉路として計算するため、周回境界にも同じ制約がかかります。

位置は積算したフレーム移動量ではなく、プロファイル上の経過時間から求めます。走行開始はフライングスタートとし、最初の周回から同じ速度変化を繰り返します。各車は別の走行ラインを使い、追い越し時の車体の重なりを避けます。

## 変更する場所

- 車種の性能と選択肢は `raceConfig.ts`、コースの形状は `circuit.ts` に分離します。車種を増やすために走行計算を分岐させる必要はありません。
- `motion.ts` は描画・Reactに依存せず、同じ車・コース・走行ラインから同じ周回を生成します。
- カメラの位置決定とシーンのライフサイクルは走行計算から分離します。カメラを変更しても車の走りは変わりません。
- 「みちばた」はコース外の高い１か所を基点に、車へ視線を向け続けます。遠いときだけ最大24m近づき、構造物が視線を遮る区間の手前から最大24mゆるやかに上がります。高さの調整はコース生成時に求め、周回境界も連続になるよう補間します。避けきれない遮蔽物は短時間の隠れとして許容し、カットや車の向きに合わせた追従は行いません。
- 車体は既存の `car-builder/carVehicles.ts` と `vehicleBody.ts` を利用します。モデルを差し替える場合は車軸の実測値と塗装対象のマテリアルも確認します。出典と加工内容は [credits.md](../credits.md) を参照してください。
- レース専用の車体質感・接地影は `carAppearance.ts`、道路の連続形状は `road.ts`、路面・芝のテクスチャは `trackVisuals.ts`、配置物は `scenery.ts` で管理します。繰り返す部品はインスタンス描画し、色の変化もインスタンス内で付けます。生成テクスチャとGPUリソースはシーン終了時に解放します。

順位やゴールは設けず、「みる くるま」で選んだ1台だけを一時的に加速する操作と、車を選び直す操作を用意します。加速中は車の後ろに発光するスピードラインとリングを表示し、幼児にも操作結果が伝わるようにします。モデル読込やWebGLが利用できない場合は、画面内の案内から再試行できます。
