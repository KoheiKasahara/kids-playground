# ドットの ボンボンぼうけん

`/games/dot-bomb` で遊べる、ボンを置いてブロックと敵を吹き飛ばすドット絵のストーリーアクションです。ガラクタだいおうにさらわれた「ピョンタ」のたまごを取りもどすため、ポンが5つのワールドを進みます。縦向き・横向きのどちらでも遊べます。

## 操作

| 操作 | スマートフォン・タブレット | PC |
| --- | --- | --- |
| いどう | 左の じゅうじパッド | 矢印キー / WASD |
| ボンを おく | 右の 赤い「ボン」ボタン | スペース / Z / J / Enter |
| とくぎ（ピョンタに のっている とき） | 右の まるい「とくぎ」ボタン | X / K / Shift |
| ひとやすみ | 右上の Ⅱ ボタン | Esc / P |

はしらの角に少しずれてぶつかっても、通れる側へ自動でよせて曲がれるようにしています（角まがりの補助）。歩いている通路の中央へも少しずつよせるため、細かい位置合わせをしなくても遊べます。

## ルール

- ボンはしばらくすると十字に爆発し、こわれるブロックと敵をまとめて吹き飛ばします。爆発はかたいはしらで止まり、ほかのボンに届くと連鎖します。
- 敵をぜんぶたおすと、はじめから見えている「とびら」が開き、入るとクリアです。ボスのステージでは、たおしたボスが落とす金のたまごを取るとクリアです。
- ポンはハートを持ってステージを始めます。爆発や敵にふれるとハートがへり、なくなると「ざんねん」になります。何度でもやり直せます。
- ★は「クリア」「ハートをへらさない」「ほしのかけらを見つける」で増えます。クリア済みと★は `createStageProgressStore` で保存し、ステージ選択でまえのステージをクリアすると次が選べるようになります。

## ピョンタ（のりもの）

ブロックの中にかくれたたまごにさわると、ピョンタが生まれて乗れます。乗っている間に敵や爆発に当たると、ピョンタが身代わりになって逃げ、ハートはへりません。色ごとに「とくぎ」がちがいます。

| 色 | とくぎ |
| --- | --- |
| みどり | ダッシュ（まっすぐ走り、ぶつかった敵をたおす） |
| あお | キック（ボンをけって すべらせる。歩いてボンにぶつかってもける） |
| ピンク | ジャンプ（ブロックやボンを1マス飛びこえる） |
| きいろ | ならべボン（向いている方向へボンを一気にならべる） |

## ワールドとしかけ

ワールドごとに見た目・敵・BGMと、遊び方を変えるしかけを1つずつ入れています。

| ワールド | しかけ |
| --- | --- |
| みどりの もり | 池（歩けないが、爆発は水の上を通る） |
| さらさら さばく | ワープつぼ（同じ数字のつぼへ移動） |
| つるつる こおりのくに | こおりの床（手をはなしても少しすべる） |
| ぐらぐら かざん | ひの あな（光ったあと周りへ炎がふき出す）・まっくらなどうくつ |
| ガラクタじょう | ベルトコンベア（ポンとボンを運ぶ）・まっくらなろうか |

各ワールドの最後はボス戦です。ボスは「あぶない時間」と「ねらいめの時間」がはっきり分かれる動き（落ちてくる場所の赤いしるし、もぐる・顔を出す、壁にぶつかってふらふら、空を飛ぶ・降りてくる、など）にし、小さな子どもでも狙いどころがわかるようにしています。ボスの体にはポンの爆発だけが効きます。

## 実装と確認

ゲーム本体は `src/games/dot-bomb/` にまとめています。`core.ts` が共通の型・爆発・ダメージ、`world.ts` が世界の生成とポンの動き・ボン・しかけ、`enemies.ts` が敵の動き、`boss.ts` がボスの動きを担当し、いずれも画面や音に触れない純粋なロジックとしてテストしています。`stages.ts` のマップ文字列からステージを組み立て、こわれるブロックとアイテムの配置はステージごとに固定の乱数で決まります。

絵は低解像度のバッファへ描いてから画面へ拡大します。`render.ts` は上の列から順に「ブロック → ボン・アイテム・炎 → いきもの」と重ねる3/4見下ろしの描き方で、`fx.ts` が破片・けむり・ゆれ・ヒットストップ時の演出を受け持ちます。おはなしは `story.ts` の台本を `StoryScreen.tsx` が文字送りで表示します。

ホームのカード・あそびかた・SEO・静的HTMLは `src/games/gameCatalog.ts` の登録を共通の情報源にし、`src/app/routes.tsx` から遅延読み込みします。
