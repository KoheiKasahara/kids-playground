# パターゴルフ

`/games/putter-golf`。ホームの3Dカテゴリから開く、物理演算で転がるボールを打つミニゴルフです。
はらっぱ・うみべ・おつきさま・ゆきやま・おかしのくに・きょうりゅう・もり・くだりざか・かわべ・たにま・こうじょう・そらのしまのコースがあり、えらんだコースのホールを続けて回ります。
コースごとに、まっすぐな道・曲がり道のほかに、正方形のひろばやコの字・Tの字・ひし形など、形のちがうホールをそろえています。
「もり」はこれまでのホールよりずっと広く、コースの上に生えた木をよけながら進みます。「くだりざか」は高台から坂とだんさでふもとへおりていきます。
「こうじょう」（おもちゃこうじょう）は、ベルトコンベアを のりついで ぐるっと まわる Uの字や、のぼりと くだりの ベルトが ならぶ ながい ラインを、スイッチで シャッターを ひらきながら すすみます。
「そらのしま」は くもに うかぶ まるい しま・ほしの しま・ハートの しまを トランポリンで わたり、たかさの ちがう しまへ のぼったり、せんぷうきの かぜに のって くねくねの みちを すすんだりします。

## あそびかた

- コース・ボールの色・「おおきい カップ」（穴を広げるやさしい設定）を選んで「スタート！」。
- 画面をひっぱって はなすと、引いた向きと反対へボールが転がります。引いた長さが強さです。コースを軽くタップすると、その場所をねらいます。
- ボタンは ← →（ねらう向き）・カメラ（ボール／ぜんたい）・やりなおすだけにして、コースの3Dビューを広く見せています。← → はカメラがボールの後ろから追うので、向きを変えると見える景色も変わります。おしつづけると少しずつ回り続けます。
- ねらっている間は、床に矢印と点線（壁で1回はね返るところまで）を表示します。ボールが止まると、そのときの位置から見通せる道すじの先を自動でねらう向きに合わせます。
- 失敗やゲームオーバーはありません。
- 水や宇宙へ落ちたら、打つ前の場所へ戻ります。
- コースのホールをすべて回ると、打った数と★のスコアカードが出ます。コースごとの いちばん多い★だけをローカルストレージに保存します（保存できない環境でも遊びは続けられます）。

## 物理の考え方

- 物理エンジンは Rapier（3D）。床・壁・カップは、見た目と同じ三角形を物理にもそのまま使います。床は多角形の外周をマス目で切り抜いて作り、こぶ・なみ・ジャンプ台の高さを付けます。カップのまわりだけは、円い穴にぴったり合う専用の三角形でつなぎます。
- 床の三角形のつなぎ目でボールが跳ねないよう、Rapier の内部エッジ補正を使います。
- 芝の上の減速は「転がり抵抗」として、重さ（重力）に比例する一定のブレーキで表します。指数的に減速させる damping と違い、ボールが いつまでも じわじわ転がり続けません。坂の重力が抵抗より強ければ、止まらず転がり落ちます。平らな芝で転がる距離はうつ強さから計算でき、テストでこの目安と実際の物理が一致することを確かめています。
- 芝のほかに、すなば・こおり・ふかふかの ゆかがあります。ちがいは転がり抵抗の係数だけで、こおりはよく すべり、ふかふかは すぐ止まります。
- 坂は、ある線から次の線までのあいだだけ下がり、その先は下がったままになる高さのしかけです。長くすればゆるい坂、短くすれば だんさになり、どちらも床は つながったままなので、ボールが下からもぐり込むことがありません。坂の上では転がり抵抗より重力が勝つので、ボールは止まらずに下まで転がります。
- 「おすすめのうち方」は、ねらう先が今より低ければ、落ちたぶんだけ よぶんに転がる距離を引いて弱くうちます（上り坂は逆に強くうちます）。
- コースの上に生えた木は、みきだけが あたり判定を持つ じゃま物です。葉にはぶつかりません。
- バンパーは反発に加えて外向きの最低速度を与えるしかけ、ダッシュパネルは通過した方向の速さを引き上げるしかけです。
- ベルトコンベアは、のっている ボールの「ベルトとの 速さの ちがい」だけを 毎ステップ へらすしかけです（転がり抵抗も ベルトに たいして かけます）。しばらく のると ベルトと 同じ速さで はこばれ、ベルトの おわりで おりて 転がります。ベルトの おわりの 先には、おりた ボールが 止まれる ゆかを のこします（かべとの あいだを 行き来しないように）。2本の ベルトの はしを つなげると、のりついで 角を まがります。
- スイッチの とびら（シャッター）は、ひらくまでは かべと 同じ あたり判定です。ボールが スイッチの 上を 転がる（または スイッチの 上に おかれる）と、あたり判定ごと なくして ゆかへ しずむ 見た目に します。いちど ひらくと そのホールの あいだは ひらいたままで、やりなおすと しまります。「おすすめのうち方」は、スイッチを おすまで スイッチより 先の みちすじの 点を ねらいません。
- トランポリンは、のった ボールを どの向きから 来ても 決まった ちゃくちてん（to）へ とばすしかけです。ふみきりと ちゃくちの 高いほうから 一定の 高さだけ 上がる 放物線を 重力から 計算するので、たかい しまへも のぼれます。とびあがりは「ジャンプ」の できごとに せず、ちゃくちでは よこの速さを 3わりに おとして はねかえりも おさえ、ころがりすぎないように します。トランポリンの 上から うつと、どの向きでも ちゃくちてんへ とびます。
- せんぷうきの かぜは、四角い 範囲の 中の ボールを 一定の 加速度で おすしかけです。転がっている間は 回転も いっしょに 変え、床との まさつで 速さが もどらないように します。とんでいる ボールも おされます。「おすすめのうち方」の 強さは、ねらう線に そった おいかぜ・むかいかぜを 転がり抵抗に 足し引きして 見つもります。
- ふうしゃの はね・うごくカベ（とびら）・歩く どうぶつは、どれも時刻から位置が決まる運動学的な剛体です。とびらは、まん中に寄っても左右にすきまが残り、はしに寄るとまん中があく幅にしてあり、どこかは必ず通れます。歩く どうぶつは、ぶつかるとバンパーと同じように外向きの速さを与えて はね返します。
- どかんは、入口に入ったボールを出口へ移し、勢いを残したまま出口の向きへ転がします。出口で入り直さないよう、出た先に重なっている どかんは通ったことにします。
- ふうしゃの はねと とびらは「待てば どく」ので、ねらいの見通し（ヒントと点線）では じゃま物として数えません。止まったボールが とびらの通り道に残らないよう、止まる位置だけ通り道の外へずらします。
- ヒントのうつ強さは、ねらう線の上の ゆかをならした転がり抵抗から計算するので、こおりを渡る線は弱く、すなばを通る線は強くなります。
- おつきさまコースは重力が小さく、こぶやジャンプ台でボールが長く浮きます。平らな所の転がり方は地球のコースとそろえるため、月の砂は転がり抵抗の係数を大きくしています。
- カップの縁の近くを遅く通るボールだけ、中心へやさしく寄せます。

## 構成

画面は物理エンジンや WebGL の内部状態を持たず、フック越しに結果だけを受け取ります。

| ファイル | 役割 |
| --- | --- |
| `golfCourses.ts` | コースとホールの定義（床の形・高さのしかけ・動くしかけ・ゆかの種類・目安のみちすじ）。まるい しま・ほし・ハートの 外周を作る 小さな関数のほかは データのみ |
| `golfPhysics.ts` | 寸法と、うつ強さ・転がり抵抗・カップへの寄りなどの純粋関数 |
| `golfGeometry.ts` | ホールの床・壁・カップの三角形。見た目と物理の共通の形 |
| `golfWorld.ts` | Rapier の世界。Three.js・DOM に依存せず、テストから本物の物理を回せる |
| `golfCamera.ts` | ねらう・おいかける・ぜんたいのカメラ位置の計算 |
| `golfScene.ts` | Three.js の見た目。繰り返す景色は形ごとの InstancedMesh にまとめる |
| `golfTerrain.ts` | まわりの じめんの おかと、いけ・かわの くぼみの高さ（見た目だけ）。物理の床には使わない |
| `golfTextures.ts` | 芝・ラフ・すな・こおり・木の いた・いわの もようを コードで かく |
| `golfRound.ts` | 1コースぶんの進みぐあい、スタンプと★、いちばん多い★の保存 |
| `usePutterGolfEngine.ts` | 固定刻みの物理と描画、ひっぱる操作、資源の確保と解放 |
| `PutterGolfPlay.tsx` | コース選び・操作ボタン・ミニマップ・カップインとスコアカード |

## 表示と端末への配慮

- 縦画面を基本に、横画面では操作盤を右に置きます。
- カメラとボールのあいだに入った景色（木や草むら）は、画素をまばらに捨てて消します。木がじゃまでボールや矢印が見えなくなるのを防ぐためで、すきとおらせる（transparent）代わりにこの方法を使うので、前後のならびが崩れず、奥行きの記録もそのまま残ります。消す範囲はカメラからボールまでの距離から決め、ホールぜんたいを見るときは消しません。
- 動きを減らす設定では、はじまりのカメラ移動・旗のゆれ・波などのアニメーションを止めます。
- 非表示のタブでは物理と描画を止め、戻ったときに経過時間をリセットします。
- 物理の読み込み失敗や WebGL の初期化失敗・コンテキスト喪失は、画面の案内から作り直せます。退出時はイベント・RAF・物理の世界・GPU資源を解放します。
- 3Dモデル・模様・効果音はすべてコードで生成し、外部の素材ファイルは追加していません。
- 芝・すな・木の いたなどの もようは 灰色に ちかい むらと すじだけを かき、コースごとの色を かけあわせて使います。ホールが変わっても作り直しません。
- 立体感を出すため、かべの ねもと・しかけの まわり・台の ねもとの じめんを 暗くし、景色の形も下のほうを暗くしています。日は ななめ よこから当てて、かげを長めに落とします。
- いけと かわは、床を見た目だけ みずの形に くりぬき、なだらかな くぼみの中に 床より ひくい水面を はります。物理の床はそのままなので転がり方は変わらず、しずむボールが水面の下に かくれる ふかさにしています。
- まわりの じめんは、コースの そばは たいらで、はなれるほど おかになります（たにまは よこに だんだんの がけ）。景色は じめんの高さに合わせて置きます。
- 遠くまで広がる じめんと数の多い景色は、光の計算が かるい材質で描きます。GPU を使わず ソフトウェアで描いている環境では、もようの 異方性フィルタを使いません。

## 検証

- 物理のテストは本物の Rapier を回し、全ホールが「おすすめのうち方」を繰り返すと めやす+2打までに入ること、ふうしゃ・すなば・こおり・ふかふか・バンパー・ジャンプ台・ダッシュパネル・月の重力の効き方、ねらいの道すじのはね返りを確かめます。
- 坂は、同じ強さでも平らなときより遠くまで転がること・坂の上では止まらないこと、だんさではボールが はねること、木に当たると はね返ることも同じ物理のテストで確かめます。
- うごくカベは うつタイミングしだいで止めたり通したりすること、どかんは 出口から勢いを残して出ること、歩く どうぶつは はね返すことも、同じ物理のテストで確かめます。
- ベルトコンベアは よわく うっても ベルトの 速さで はこぶこと・さからうと おしもどすこと、シャッターは スイッチを ふむまで 通さず ふむと 通すこと、トランポリンは どの向きから のっても ちゃくちてんへ とび たかい しまへも のぼれること、かぜは おいかぜで 遠く・むかいかぜで 近くまでしか 転がさず おすすめの 強さも 変わることを 確かめます。
- コースの データの テストでは、トランポリンの ちゃくちてんが ゆかの上で みちすじが それを 通ること、ベルトの おわりの 先が 止まれる ゆかで あること、シャッターが みちを かべから かべまで ふさぎ みちすじが 先に スイッチを 通ることを 確かめます。
- 形のテストでは、床の面積・向き・カップの縁の円さ、ティーとカップのまわりの平らさ、壁の位置、坂の高さの付き方、台が坂で下がった床より下まであることを確かめます。
- 見た目の地形のテストでは、まわりの おかが コースの そばで もりあがらないこと、いけ・かわの くぼみが みずの中だけで ふちと床の はしで床とつながることを確かめます。
- 画面とフックのテストでは、選択・操作・カップインから結果までの流れ、← → がねらう向きを変えること、ホールぜんたいを見るときは景色を消さないこと、資源の確保・解放・再試行を確かめます。
- ブラウザの動作確認は `e2e/putter-golf.smoke.spec.ts`。
