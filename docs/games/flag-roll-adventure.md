# こっきコロコロぼうけん

> この文書は長期的な設計・運用方針を扱う。個別機能の最新仕様は GitHub Issue、現在の詳細挙動・パラメータは実装コードとテストを正とする。

## 概要

選んだ国旗ボールが自動で転がっていく様子を見守るミニゲームです。プレイヤーはコースを直接操作せず、物理的にどちらの経路へ進んだかによって、その先の見え方が変わります。

## 主な特徴

- 操作を最小限にした「見守る」遊びで、進行に必要な操作をプレイヤーに要求しません。
- コースはいくつかのエリアに分かれ、出口で自然に次のエリアへつながります。分岐がある場合も、通った出口によって行き先が決まるだけで、選択操作は挟みません。
- どのルートを通っても、必ずゴールへたどり着けることを設計の前提にしています。

## コースの見どころとテンポ

- そら：プロペラと左右へ渡る長い滑り台。
- もり：きのこへ集めて斜めにジャンプし、着地側の出口で洞窟・川へ分岐。
- どうくつ：入口から大砲へ集め、発射から着地の坂へつなぐ。
- かわ：坂に沿う急流で加速し、ジャンプしてから下流の出口へ入る。
- くも：大きなバネで横へ跳び、受け坂からゴールへ進む。
- ゴール：二段の滑り台からカップへ転がり込む。

小ピンを等間隔で敷き詰める構成は避け、加速できる空間と着地する場所を用意する。仕掛けの数や接触密度ではなく、実際の発動・両ルートへの分岐・所要時間・救済なしの完走を固定ステップで検証する。バネの真上への往復や、ジャンプより手前にある出口は作らない。

## 技術 / 主要実装

- 2D物理演算に Matter.js を使い、エリアをまたぐ移動をカメラの遷移と合わせて表現します。
- `src/games/flag-roll-adventure/` にエリアデータと状態遷移をまとめ、エリアの追加・変更はデータの拡張として行います。
- 進行不能な状態を検知して復帰させる救済処理を、通常の物理挙動とは別の責務として持ちます。

## 設計上の注意

- コースの分岐や仕掛けは、子どもが操作しなくても自然に進み続けることを最優先にして設計します。
- 停滞・詰まりを完全になくすことはできない前提に立ち、検知して抜け出す救済の仕組みを常に用意します。これが無いと「操作なしで進む」という前提が成立しません。
- 演出（見た目・カメラワーク）と物理挙動の責務を分け、演出側の変更が物理の再現性に影響しないようにします。
- コースを増やす際も、「操作なしで必ず完了する」という保証を壊さないことを優先し、賑やかさより完了保証を優先します。
