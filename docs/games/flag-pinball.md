# こっきピンボール

> この文書は長期的な設計・運用方針を扱う。個別機能の最新仕様は GitHub Issue、現在の詳細挙動・パラメータは実装コードとテストを正とする。

## 概要

国旗そのものをボールに見立てて盤面へ打ち出す、2D物理のアクショントイです。正解・不正解を競うクイズではなく、国旗を選ぶ・見分ける楽しさと、盤面で弾かれる物理挙動そのものを楽しむことを重視しています。

## 主な特徴

- 遊びの主役は「当たること」ではなく「弾かれ方・転がり方」で、得点はおまけの要素です。
- 盤面の見た目はテーマとして複数用意しており、テーマごとに配置や雰囲気を変えられます。
- 盤面には、タップで反応するおもちゃ（トイ）を置けます。おもちゃは遊びに必須ではなく、操作しなくても最後まで成立します。

## 技術 / 主要実装

- 2D物理演算に Matter.js を使い、盤面の物理はヘッドレスに計算してDOMへ直接反映します。
- `src/games/flag-pinball/boardConfigs/` に盤面データをテーマ単位で持ち、テーマの追加は既存コードを変えずデータを足す形で行います。
- おもちゃは `ToyRuntime` という共通インターフェースでエンジンと接続し、物理挙動とテーマごとの見た目を分離しています。

## 設計上の注意

- 物理演算とReactの描画は境界を分け、物理エンジンの毎フレームの状態をReactの再レンダーへ直接持ち込みません。
- 盤面は論理座標系で定義し、実機の画面サイズには依存させません。表示側で拡縮するだけにすることで、物理パラメータを端末ごとに調整しない構造を保っています。
- どんな配置・操作でも遊びが有限時間で終わることを前提にし、停滞を検知して抜け出す仕組みを設計の一部として持たせます。
- 新しいテーマやおもちゃを追加するときも、盤面データとおもちゃの物理・見た目という既存の責務分離を崩さないようにします。
