# でんしゃの たび

`/games/train-journey`。ホームの3Dカテゴリから開く、勝敗のない電車あそびです。
サーキットレースの自動走行、カメラ計算、環境反射、GamePlaySurface、共通音声基盤を活用しています。

## あそびかた

- しんかんせん・きかんしゃ・かもつれっしゃから選び「しゅっぱつ！」。
- 電車は3両で自動走行し、にじいろ駅に戻ると約3秒停車して再出発します。
- 「ポイント」またはコース上の同じ標識で次の行き先を切り替えます。青は高架と赤いトラス橋、緑は森のトンネルです。ミニマップ、レール上の矢印、実際のレバーが連動します。
- 先頭が分岐を通過した後の操作は次の周回に反映されます。後ろの車両も先頭と同じルートを通ります。
- 「かそく！」は2.4秒間の一時加速。連打で最高速度は増えません。停車中に押すと出発します。
- 「おいかける」「ぜんたい」で視点を選べます。全体表示では指で回転・ピンチで拡縮でき、「ぜんたいに もどす」で戻ります。
- 汽笛、一時停止、電車選び直し、音のオン・オフも用意しています。

## 実装

- `journeyModel.ts`: 共通区間と2分岐の接続グラフ、距離による等速サンプリング、滑らかな加減速、駅停車、加速、編成の走行履歴。
- `journeyScene.ts`: 連続レール、Kenney枕木のインスタンス、開口のあるトンネル、立体交差、橋脚、駅、街並み、森、池、風車。樹木・橋脚は線路を避けて配置します。
- `useTrainJourneyEngine.ts`: GLB読込、編成描画、カメラ、マーカー投影、RAF、ResizeObserver、音・煙・加速表現、WebGL復旧、リソース破棄。
- `TrainJourneyPlay.tsx` / CSS: 選択と走行のUI。縦画面を基本に、横画面は操作盤を右に配置します。

GPU描画は最大40fps、DPRは1.7まで。木・花・橋脚などは5種類のインスタンス描画、レールは結合したジオメトリです。追加GLBは8ファイル合計908,620バイト、共通パレットは512×512。高解像度写真・物理エンジン・ポストプロセスは追加していません。モデルとPNGは既存PWA設定でキャッシュされます。

非表示タブではRAFと走行を停止し、復帰時に経過時間をリセットします。動きを減らす設定では全体カメラから開始し、煙・加速線・風車・水面アニメーションを抑えます。ロード失敗／WebGL利用不可は再試行でき、コンテキスト復帰時はシーンを作り直します。終了時はイベント、カメラ操作、RAF、GPU資源を解放します。

## 検証・自己レビュー

- 数値テスト: 分岐と合流の位置・接線、坂の高さ、上下交差の間隔、両ルートから駅への帰着、切替中も編成が分かれないこと、周回をまたぐ連続性、加速の期限・上限、フレームレート差、全方位の坂で車両が直立する姿勢、分岐に先行する台車の位置。
- UIテスト: 3車種、選択の保持、2か所のポイント操作の同期、停止と加速による再開、カメラ、消音、読込エラーと再試行、動きを減らす設定。
- ブラウザテスト: ホームからの遷移、実GLB描画、走行・加速終了・停止、縦横の主要ボタンの大きさと表示、モデル取得失敗、WebGL初期化失敗／コンテキスト復帰、画面離脱。
- 実画面の自己レビューで、駅舎に遮られる追従カメラを線路内側へ移し、近景の大きな駅名看板を全体表示時のみ表示するよう修正しました。全体カメラの霧を外し、分岐先の矢印を追加しました。サーキットレースの実画面も比較対象として確認しています。
- コードの自己レビューでは、進行方向だけから求める回転が北向きの坂で上下反転し得る点を修正しました。水平の向きと坂の傾きを分け、車両と枕木の上向きを保つ回帰テストを追加しています。
- 森ルートの実画面レビューでは、手前の高架橋が列車を大きく隠す区間を修正しました。この区間は橋の東側から追従し、トンネル内では屋根を突き抜ける煙を表示しません。

実行コマンド: `npm run verify`、`npx playwright test e2e/train-journey.smoke.spec.ts --workers=1`。

2026-09-10の最終結果: lint・型チェック・本番ビルド成功、332ファイル／4,900テスト成功（新ゲームの数値・UIテスト15件を含む）、Chromiumブラウザテスト4件成功。390×844、320×568、844×390、667×375の主要操作と表示領域を確認し、1200×900でも目視確認しました。実測例は機関車の森ルートで31描画呼出／85,011三角形。静的HTML生成と、電車関連12アセットのPWAキャッシュ収録も確認しています。

全体検証で判明した既存SEOテスト2件のCRLF依存は、比較時の改行正規化で修正しています。公開HTMLやrobots.txtの内容は変更していません。
実機スマートフォンのGPU性能・Safariでの検証は別途必要です。
