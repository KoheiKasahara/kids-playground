# ピアノであそぼう Phase 1 設計

## 目的

幼児が説明を読まずに大きな鍵盤へ触れ、自由演奏を楽しめるミニゲームを提供する。Phase 1では得点・判定・曲再生を持たず、Phase 2の自動演奏から再利用できる最小限のノート・発音基盤までを実装する。

## URLと画面

- URL: `/games/piano-play`
- 画面を開くと、戻る操作、短い案内、C4〜B4の1オクターブ（白鍵7本・黒鍵5本）を表示する。
- スマホ縦は横スクロールなしで全鍵盤を表示する。低い横画面は案内と鍵盤を左右に分け、PCでは鍵盤幅を760px以下にする。

## データと発音の責務

- `notes.ts`: 音名、オクターブ、周波数、白鍵／黒鍵、表示順を持つ単一のノート定義。
- `pianoAudio.ts`: Web Audio APIで各打鍵を独立voiceとして合成する。`startNote` / `stopNote` は押している長さに従う自由演奏、`playNote(note, durationMs)` は将来の曲再生から利用できる。
- `PianoKeyboard.tsx`: 鍵盤表示とPointer Eventsを担当し、音声APIを直接参照しない。
- `PianoPlay.tsx`: 入力中のポインタ、発音voice、視覚フィードバックを結び付け、画面離脱時にすべて破棄する。

音色は外部録音を使わず、三角波の基音と小さな正弦波の倍音へ短いAttack・Decay・Releaseを付ける。発音ごとにOscillator/Gainを分け、同音連打と複数音を許可する。

## Phase 1の非目標

曲選択、自動再生、楽譜、採点、録音・保存、MIDI、音色切り替えは実装しない。
