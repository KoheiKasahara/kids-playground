# 「いろまぜクイズ」基本設計

## 概要

色の絵の具を混ぜた結果を、大きな色パネル4択から選ぶ未就学児向けクイズです。文字で色名を答える必要はありません。問題データはすべてアプリに同梱し、初回読み込み後もPWAのキャッシュで遊べます。

## 画面と進行

色まぜクイズには難易度選択がありません。

| 画面 | URL |
| --- | --- |
| 開始 | `/games/color-mix-quiz` |
| プレイ | `/games/color-mix-quiz/play` |
| 結果 | `/games/color-mix-quiz/result` |

```text
ホーム → 開始 → 10問プレイ → 結果 → もういちど
```

旧 `/level` と `/:level/play` のURLは、既存のブックマークが空画面にならないよう `/play` へリダイレクトします。

## 問題タイプと出題バランス

問題プールは全26問です。1プレイは10問で、同じ問題は、プールが10問以上ある限り同じゲーム内で重複しません。問題の順番は毎回シャッフルします。

| 種別 | 1プレイ | プール | ねらい |
| --- | ---: | ---: | --- |
| 2色足し算 | 7問 | 16問 | 分かりやすい色どうしの混色を中心にする |
| 引き算 | 2問 | 6問 | 2色レシピを逆向きに考える |
| 3色足し算 | 1問 | 4問 | 3色を混ぜる特別感を楽しむ |

種別の問題数が将来不足した場合は、未使用の他種別で補充します。プールが10問未満になった場合でも、全問を一度使い切るまでは重複しません。

### 色の引き算

引き算は現実の絵の具から色を物理的に取り除く意味ではありません。

> この色は2色を混ぜてできた。そのうち片方を取ると、残りは何色？

というゲーム上の逆算ルールです。たとえば「むらさき − あお → あか」は「あか + あお → むらさき」の逆です。すべての引き算問題は、既存の明快な2色レシピを `recipeId` で参照して検証します。

## 選択肢と演出

- 選択肢は常に4つ。正解は必ず1つだけで、同じ色の重複はありません。
- 近い色相・明度だけが違う色をおとりに使いません。子どもがはっきり別の色と認識でき、少し考える余地のある4択にします。
- 白・黒を材料にする2色問題は、ピンク、水色、ミント、ラベンダー、ネイビー、マルーンのように結果が明快なものだけを採用します。
- 茶色、灰色、黒っぽい濁色ばかりになる3色問題は採用しません。
- 加算は `＋`、逆算の引き算は `−` を表示します。既存の絵の具パネル、混色アニメーション、正解・不正解演出、効果音を共用します。

## データと検証

`ColorMixProblem` は `two-color-addition`、`subtraction`、`three-color-addition` の判別可能なunion型です。データ検証では、ID、16進色、4択の一意性、正解が1つであること、引き算が参照レシピの逆になっていることを確認します。

テストでは、10問の出題バランス、ゲーム内の問題重複防止、選択肢の整合性、引き算の逆レシピ検証、他クイズの難易度選択に影響しないことを確認します。
